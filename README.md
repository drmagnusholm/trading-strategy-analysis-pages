# Trading Strategy Analysis

[Open the live app](https://drmagnusholm.github.io/trading-strategy-analysis-pages/)

A standalone browser app for comparing trading strategies, monthly and annual returns, leverage, drawdowns, sampling uncertainty, and autocorrelation.

Use a simulated sample, paste or upload a return series, or load public Binance data. Calculations run in your browser. You can also download `index.html` and open it locally; chart libraries load from public CDNs.

GitHub Pages publishes `index.html` from the root of the `main` branch. This repository contains a publication copy of the app. To update the site, replace `index.html` with the latest app HTML and commit it here.
